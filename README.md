# ReEngineered_DataVizCapstoneProject_InPython
Re-engineering the original CALCOFI Ocean Temperature Analysis Capstone Project using Python. Currently in the testing and development phase, with ongoing backend implementation and integration of the original project. Includes data cleaning, exploratory data analysis, statistical modeling, Linear and Ridge Regression, correlation analysis, ANOVA, and interactive geospatial mapping of ocean temperature patterns in the California Current System.

Original Capstone Project: https://afsana25.github.io/DataVizCapstoneProject/
